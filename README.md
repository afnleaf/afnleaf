# WELCOME TO MY GITHUB PROFILE

I solve complex problems by architecting, building, and deploying robust, end-to-end systems from the ground up. My work demonstrates true system ownership—from first-principles analysis to full self-hosted deployment.

---

## Featured Projects

-   **🌎 [PaleoMap3D](https://github.com/afnleaf/paleomap3d)** - An interactive 3D globe visualizing continental drift, built on a custom data pipeline in Rust, C, and Python. **[Live Demo](https://paleomap3d.org)**

-   **🤖 [OW2 Replaycode OCR](https://github.com/afnleaf/ow2-replaycode-ocr)** - A high-accuracy Discord bot that extracts game replay codes from screenshots using a Vision Language Model (VLM).

-   **🎨 [Deadlocker.tv](https://github.com/afnleaf/deadlocker.tv)** - A community hub and interactive tactical map for the game *Deadlock*, built with a high-performance Go backend and Canvas API. **[Live Demo](https://deadlocker.tv/map)**

-   **🚀 [HQmons & Pokepastefix](https://github.com/afnleaf/hqmons)** - A high-performance image server (Bun/Elysia.js) and browser extension serving 800+ daily active users. **[Live Demo](https://chiy.uk)**

-   **🏒 [Hockey3D](https://github.com/afnleaf/hockey3d)** - A 3D visualization tool that reconstructs NHL games from play-by-play data using Rust and Three.js. **[Live Demo](https://stezup.dev/hokej)**

-   **📹 [Deadlock Broadcast Agent](https://github.com/afnleaf/deadlocktopmatch)** - An autonomous agent that automates game broadcasting using OpenCV for real-time state analysis.
